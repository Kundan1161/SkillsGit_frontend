# Growth Engine

## Overview

A growth engine for digital products covering search optimization, app store visibility, referral mechanisms, email campaigns, and organic user acquisition. The foundational premise: the best marketing is a product people love.

## When to use

Use this skill when defining the growth strategy for a new launch, diagnosing where a funnel is leaking, designing a referral or viral loop, or building a multi-channel growth roadmap.

## How to apply

### Core Framework: Pirate Metrics (AARRR)

Apply the AARRR model:
- **Acquisition** - how users find you
- **Activation** - first meaningful experience
- **Retention** - return behavior
- **Revenue** - monetization
- **Referral** - users bringing other users

Define explicit KPIs at each stage before optimizing any single channel.

### Key Strategies

**SEO & Discovery**
- Target high-intent keywords and long-tail terms with lower competition
- Build topical authority around a small set of core concepts
- Capture branded search early; non-branded scales later

**Viral Mechanisms**

Three loops to consider:
1. Organic word-of-mouth (target K-factor >= 0.3 as a healthy floor)
2. Insight or content sharing (users share outputs they're proud of)
3. Referral rewards program (explicit incentive structure)

**Onboarding Sequence**

A structured 14-day email campaign with triggers for activation, education, and re-engagement. Send based on user behavior, not calendar.

**Launch Strategy**
- **Pre-launch**: Build waitlist, prime community channels
- **Launch day**: Coordinated execution across Product Hunt and relevant communities
- **Post-launch**: Capture the press momentum into a sustained content rhythm

### Specialized Workstreams

Common growth motions to plan separately:
- Growth audit (current-state diagnosis)
- SEO analysis (keyword coverage, content gaps)
- ASO optimization (app store metadata and creative)
- Viral loop design
- Email sequence construction
- Launch plan
- Referral program design
