# Gradio

## When to use

Use this skill when building interactive web UIs and ML demos in Python — wrapping a model in a shareable demo, prototyping a research artifact, building an internal tool, or deploying to Hugging Face Spaces.

## How to apply

Choose between three core patterns based on complexity. Use built-in components for inputs/outputs. Wire events using each component's supported listeners. Test locally before pushing to Spaces.

## Three Core Patterns

1. **Interface** — high-level wrapper that connects a function to input/output components with minimal code.
2. **Blocks** — flexible, lower-level system enabling explicit event wiring and custom layouts.
3. **ChatInterface** — specialized wrapper for chatbot applications.

## Built-in Components

Text inputs, numeric fields, sliders, checkboxes, dropdowns, radio buttons, media handlers (image, audio, video), file uploads, chatbots, buttons, markdown renderers, HTML elements.

## Custom Components

Subclass `gr.HTML`, use `html_template` with JavaScript expressions, `css_template` for styling, and `js_on_load` for interactivity. Useful for reusable widgets like a star-rating component.

## Event System

All event listeners share a consistent signature with parameters for inputs/outputs, API configuration, queue management, and progress display. Components support different events — buttons support `click`, textboxes support `change`, `input`, `select`, and `submit`.

## CLI Tools

- `gradio info` — Retrieves endpoint and parameter documentation in JSON format.
- `gradio predict` — Sends predictions to remote Gradio applications, supporting complex data types including file uploads.
