# Cloudflare Web Performance Audit

## When to use

Use this skill when auditing web performance with Chrome DevTools MCP — measuring Core Web Vitals (LCP, CLS, INP), analyzing network and DOM, identifying render-blocking resources, and producing prioritized recommendations with quantified impact.

## How to apply

Verify the Chrome DevTools MCP tools are available before starting any audit. Bias toward current documentation over pre-training for specific thresholds. Confirm findings via network and DOM analysis before recommending changes. Skip non-issues (e.g., render-blocking resources with 0 ms impact). Prioritize ruthlessly and quantify savings.

## Audit Workflow

1. **Pre-flight check** — Confirm Chrome DevTools MCP is connected and reachable.
2. **Capture baseline** — Run a fresh trace on the target URL. Record LCP, CLS, INP, TBT, TTFB.
3. **Identify framework / bundler** — Detect Next.js, Astro, SvelteKit, Vite, etc. to tailor recommendations.
4. **Network analysis** — Look for waterfall depth, large unoptimized images, missing cache headers, render-blocking CSS/JS.
5. **DOM / rendering analysis** — Check for layout shifts (CLS), main-thread blocking tasks (INP/TBT), excessive DOM size.
6. **Accessibility quick-pass** — Surface obvious a11y issues (color contrast, missing alt, focus traps).
7. **Quantify impact** — For each finding, estimate the metric improvement (e.g., "Defer this 280 KB script → −1.2 s LCP").
8. **Prioritize** — Order by `impact × ease`. Lead with quick wins.
9. **Recommend** — Provide concrete code or config changes, not vague advice.

## Output Format

For each issue:

- **Metric affected**: LCP / CLS / INP / TBT / TTFB
- **Evidence**: trace snippet, file path, network entry
- **Estimated impact**: ms saved or score points
- **Fix**: exact code/config change

Keep all quoted snippets under 125 characters and mark them as quotes.

## Common Wins

| Issue | Fix |
|-------|-----|
| Large hero image | Use `<img>` with `srcset`, AVIF/WebP, explicit dimensions |
| Render-blocking CSS | Inline critical CSS; defer the rest |
| Unused JS | Tree-shake, code-split, dynamic import |
| Long tasks > 50 ms | Break with `scheduler.yield()` or `requestIdleCallback` |
| Missing caching | Set `Cache-Control: public, max-age=31536000, immutable` for hashed assets |
| Layout shift on font swap | `font-display: optional` or preload + `font-display: swap` with size-adjust |

## Constraints

- Don't recommend changes without confirming the issue in the trace or DOM.
- Don't repeat advice that doesn't apply to the detected framework.
- Don't produce a wall of low-impact findings — focus on the top 5–10 that move metrics.
