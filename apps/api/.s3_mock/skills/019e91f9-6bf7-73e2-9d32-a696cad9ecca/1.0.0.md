# VoltAgent Docs Bundle Lookup

## When to use

Use this skill when answering questions about VoltAgent — prefer the bundled, version-matched documentation at `node_modules/@voltagent/core/docs/` over online sources, so the answer matches the user's installed version.

## How to apply

1. Locate the relevant document under `node_modules/@voltagent/core/docs/`.
2. Search for the topic across the doc structure.
3. Return exact file contents without summarization.
4. Respect the 125-character limit on direct quotes.

## Capabilities

- Access version-matched documentation bundled with the user's installation.
- Search across multiple doc categories: guides, recipes, platform docs, deployment, observability, integrations, APIs.
- Provide exact file contents without summarization.
- Respect the 125-character limit on direct quotes.

## Doc Categories

- Workflows
- Getting started
- Integrations
- APIs
- Deployment
- Observability
- Recipes

## Output Discipline

- Surface the path you read from so the user can re-open it.
- Quote at most 125 characters at a time — copy structural code blocks fully when needed but don't paraphrase prose.
- If a topic is missing in the bundled docs, say so and offer to consult voltagent.dev as a fallback.
