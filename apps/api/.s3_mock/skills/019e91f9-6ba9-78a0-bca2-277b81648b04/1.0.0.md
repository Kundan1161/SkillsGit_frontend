# Vision Model Training on Hugging Face Jobs

## When to use

Use this skill when training or fine-tuning computer vision models — object detection, image classification, or segmentation — using Hugging Face Jobs infrastructure.

## How to apply

Verify prerequisites (paid plan, write token), validate the dataset format with `dataset_inspector.py` (the #1 cause of training failures), submit via `hf_jobs()` MCP tool or `HfApi().run_uv_job()`, pass the token via `secrets`, configure `push_to_hub`, and enable Trackio for monitoring.

## Core Capabilities

- **Object Detection** — D-FINE, RT-DETR v2, DETR, YOLOS
- **Image Classification** — timm models (MobileNetV3, ResNet, ViT) and Transformers classifiers
- **Segmentation** — SAM and SAM2 with bbox or point prompts

## Critical Prerequisites

1. Paid HF account (Pro, Team, or Enterprise)
2. Authentication with a write-capable token
3. Dataset validation via `dataset_inspector.py`
4. Proper timeout configuration (minimum 2–4 hours for production jobs)

## Dataset Requirements

| Task | Required Columns / Format |
|------|---------------------------|
| Object Detection | `objects` column with `bbox` (xywh or xyxy) and `category`; `image_id` auto-generated |
| Image Classification | `image` (PIL) and `label` (int or string); common names like `label`, `class` auto-detected |
| SAM/SAM2 | `image`, `mask`, prompt data via `prompt` JSON, `bbox`, or `point` (xyxy) |

## Key Directives

1. **Job submission** — `hf_jobs()` MCP tool or `HfApi().run_uv_job()` with proper token injection.
2. **Token handling** — pass via job secrets; inject into `training_args.hub_token` before Trainer init.
3. **Boolean flags** — bare flags for `bool` fields; explicit values for `Optional[bool]` fields.
4. **Required flags** — `--no_remove_unused_columns`, `--push_to_hub`, metric configuration.
5. **Timeout** — minimum 1–12 hours depending on dataset size.
6. **Monitoring** — Trackio dashboard enabled automatically for OD training.

## Recommended Starting Models

| Model | Params | VRAM | Hardware | $/hr |
|-------|--------|------|----------|------|
| D-FINE Small | 10.4M | <16GB | t4-small | $0.40 |
| MobileNetV3 | 2.5M | <16GB | t4-small | $0.40 |
| SAM2 Hiera-Small | 46M | <16GB | t4-small | $0.40 |

## Training Workflow

1. Verify prerequisites and account status.
2. Validate dataset format with the inspector script.
3. Ask user about dataset size, validation split, hardware preference.
4. Prepare training script with appropriate configuration.
5. Submit job and report ID, monitoring URL, time estimates, and cost.
