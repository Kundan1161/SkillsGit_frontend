# AlloyDB Basics

## When to use

Use this skill when managing AlloyDB for PostgreSQL — creating clusters and primary instances, configuring backups, integrating with AlloyDB MCP tools, or troubleshooting authentication and access.

## How to apply

Enable the AlloyDB API via `gcloud`, create a cluster with network and authentication configuration, then deploy a primary instance with the desired compute resources. Prefer IAM database authentication or a secret manager over plaintext passwords for production deployments. Consult the linked reference areas for deeper architecture, CLI, client library, MCP, Terraform, and IAM details.

## Overview

AlloyDB for PostgreSQL is a managed, PostgreSQL-compatible database service designed for enterprise-grade performance and availability. The service implements independent scaling through a disaggregated compute and storage architecture. It offers AlloyDB AI with capabilities including vector search, hybrid search functionality, natural language processing, conversational analytics, and inference operations.

## Setup Instructions

The quick start has three primary steps:

1. Enable the AlloyDB API via `gcloud` command.
2. Establish a cluster with network and authentication configuration.
3. Deploy a primary instance with specified compute resources.

Security note: password-based authentication should avoid cleartext transmission. Use IAM database authentication or secret management tools for production deployments.
