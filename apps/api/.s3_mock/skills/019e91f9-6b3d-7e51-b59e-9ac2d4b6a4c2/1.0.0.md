# Hugging Face Datasets

## When to use

Use this skill when interacting with the Hugging Face Dataset Viewer API — exploring, paginating, filtering, or extracting datasets — and when uploading new datasets to the Hub.

## How to apply

Use the Dataset Viewer API for read-only operations against existing datasets. URL-encode all query parameters; offsets are zero-based. For dataset creation use the web UI or `npx @huggingface/hub` CLI for batch uploads.

## Key Endpoints

- **Validation** — `/is-valid` checks dataset availability.
- **Structure** — `/splits` lists configurations and splits.
- **Preview** — `/first-rows` fetches initial rows.
- **Pagination** — `/rows` retrieves rows (max 100 per request).
- **Search** — find text matches across string columns.
- **Filtering** — `/filter` applies predicates and sorting.
- **Export** — parquet URLs and dataset statistics.

## Recommended Workflow

1. Validate the dataset exists with `/is-valid`.
2. Resolve the appropriate config and split via `/splits`.
3. Preview content with `/first-rows`.
4. Paginate (`/rows`) or search/filter (`/filter`) as needed.
5. For bulk export, use the parquet URLs returned by the export endpoint.

## Dataset Creation

Multiple paths:

- **Web UI** — https://huggingface.co/new-dataset
- **CLI** — `npx @huggingface/hub` for batch uploads
- Mark repos as private during creation if needed
