# Sentry Presentation Creator

## When to use

Use this skill when creating presentations, slides, or data decks with Sentry branding — typically as a single-file HTML build for easy distribution.

## How to apply

Gather requirements first. Assess data rigorously — only create Recharts visualizations when **real quantitative data** exists in source content; never fabricate numbers. Scaffold the project with React + Vite + Recharts. Build slide system with keyboard nav. Output via `vite-plugin-singlefile` for distribution.

## Workflow

1. **Gather requirements** — topic, slide count, data needs, narrative structure.
2. **Assess data rigorously** — only create Recharts visualizations when real quantitative data exists in source content; use text-based layouts (cards, tables, bullets) for qualitative content; **never fabricate numbers**.
3. **Scaffold the project** — generate `index.html`, `package.json`, `vite.config.js`, and `src/` files with React + Vite + Recharts setup.
4. **Build the slide system** — keyboard navigation, progress indicator, Sentry-styled layouts using CSS variables and design tokens.
5. **Create charts conditionally** — only include `Charts.jsx` and Recharts if slides have real data; omit both entirely if the content is purely narrative.
6. **Apply Sentry design system** — Rubik typography, official color palettes, semantic variables, animations from references.
7. **Output single-file HTML** — distributable build via `vite-plugin-singlefile`.

## Key Constraints

- No fabricated data in visualizations.
- No category tag pills above headings.
- All SVG logos pulled from official reference files, never hardcoded.
- Keyboard navigation + transparent overlay nav with dot indicators.
- Staggered fade-in animations with `.anim` and delay classes.

## Output

A self-contained `dist/index.html` that opens in any browser, contains all assets inline, and supports keyboard navigation (← →).
