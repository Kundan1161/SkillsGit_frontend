# @skillsgit/web-creator

The authoring studio. Next.js 15 + React Flow visual builder for `skills.md`.
Runs on port **3001**, dark by default.

## Quickstart

From the monorepo root:

```bash
pnpm install        # only run from root — installs the workspace
pnpm dev            # starts api (8000), marketplace (3000), creator (3001)
```

Or just this app:

```bash
pnpm --filter @skillsgit/web-creator dev
```

Then open <http://localhost:3001>.

## Routes (Phase 0 stubs)

| Path | What it is |
|---|---|
| `/` | My drafts (empty state) |
| `/skills/new` | New skill chooser — blank / import / template |
| `/skills/[id]/builder` | The React Flow canvas (interactive, empty) |
| `/skills/[id]/config` | Metadata, AI runtime, pricing form (placeholder) |
| `/skills/[id]/preview` | Compiled `skills.md` preview split view (placeholder) |
| `/skills/[id]/sandbox` | Run against models (placeholder) |
| `/skills/[id]/publish` | Publish wizard (placeholder) |
| `/skills/[id]/versions` | Version history timeline (placeholder) |
| `/import` | Source picker for existing projects (placeholder) |
| `/templates` | Template gallery by industry |
| `/settings` | Links to marketplace settings |
| `/sign-in` · `/sign-up` | Auth forms (UI only) |
| `/_design` | Kitchen-sink page for visual regression |

## What's actually wired in Phase 0

- App shell, dark-default `ThemeProvider`, top nav, footer, user menu.
- Every shadcn primitive from `shared/design-system.md`.
- React Flow canvas at `/skills/[id]/builder` — empty graph with
  pan/zoom, dotted background, controls, and minimap.
- Zustand store (`lib/builder/store.ts`) — shape only.
- Templates list metadata (`lib/builder/templates.ts`).

## What's intentionally **not** here yet (Phase 3+)

- Graph → `skills.md` compiler & inverse parser.
- Per-node-kind inspector forms.
- Drop handler on the canvas (palette chips are draggable, but the canvas
  doesn't yet create nodes from them).
- Autosave + snapshots + undo/redo.
- Sandbox runtime, publish flow, import pipelines.
- Real auth, real session.

See `prompts/skill-creator/00-overview.md` for the full spec and the
phase-3 acceptance criteria.

## Conventions

- TypeScript strict, `@/*` path alias.
- Server Components by default; client only where interactivity demands it.
- Design tokens live in `packages/ui/src/styles/tokens.css` — both
  marketplace and creator import the same file.
- Talk to the backend via `lib/api.ts` until `@skillsgit/api-client` is
  regenerated by `pnpm codegen`.
