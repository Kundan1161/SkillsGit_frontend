## Source build scripts

Each deck was generated by a `pptxgenjs` (Node) script. Re-runnable for edits:

- `scratch/deck-build/build-deck.js` (technical-team)
- `scratch/investor-build/build-investor-deck.js` (investor-pitch)
- `scratch/creator-onboarding-build/build-creator-deck.js` (creator-onboarding)

`scratch/` is the personal working area — scripts kept there so they don't
clutter the tracked repo. To regenerate any deck:

```bash
cd scratch/<build-folder>
node build-*.js
```

## QA done at build time

Each deck was validated:

1. `markitdown` text extraction grep for placeholder remnants (`lorem`, `ipsum`, `TODO`, `[insert`, `xxx`, etc.) — **all clean**.
2. Per-slide JPG export via PowerPoint COM, then visual inspection for overlapping elements, text overflow, low-contrast text, uneven margins, etc. — **all issues fixed and re-verified**.
