# VoltAgent Project Creation Guide

## When to use

Use this skill when creating a new VoltAgent project from scratch — choosing server framework, AI provider, and initial agents/workflows.

## How to apply

Offer the user three paths and pick based on their preference. Default to the automatic CLI for speed; offer the interactive guide for learners; offer manual installation when integrating into an existing repo.

## Three Paths

1. **Automatic Setup** — Run the CLI command and handle prompts.
2. **Interactive Guide** — Walk through each configuration step.
3. **Manual Installation** — Set up all components from scratch.

## Requirements

- Node.js 20+ (20.19.0+ recommended).
- API key for your model provider (except Ollama).
- Git optional for repository initialization.

## Main Creation Command

```bash
npm create voltagent-app@latest
```

The CLI handles:

- Project naming
- Server framework selection (Hono / Elysia)
- AI provider choice (OpenAI, Anthropic, Google, Groq, Mistral, Ollama)
- API key input
- Dependency installation

## Supported Model Providers

OpenAI, Anthropic, Google Generative AI, Groq, Mistral, Ollama.

Format: `openai/gpt-4o-mini` or `anthropic/claude-3-5-sonnet`.

## Manual Setup

For users preferring manual installation, the source repo provides step-by-step instructions for:

- TypeScript configuration
- Environment setup
- Tool creation
- Workflow definition
- Server initialization
